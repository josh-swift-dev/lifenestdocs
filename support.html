Welcome to LifeNest Docs Support

Need help organizing documents, setting reminders, or unlocking Pro? You'll find answers to common questions below.

How do I add a document?

Open LifeNest Docs and select the option to add a document. You can import an existing file or use your device's camera to capture a document.

How many documents can I save for free?

The free version allows you to save up to 7 documents.

What does LifeNest Docs Pro include?

LifeNest Docs Pro removes the document limit, allowing you to organize unlimited documents. The lifetime unlock is a one-time $1.99 purchase in the US, subject to the price displayed by the App Store. There is no recurring subscription.

How do I restore my purchase?

Open the app's Settings screen and select Restore Purchases. Make sure you're using the Apple Account associated with your original purchase.

How do reminders work?

Add an expiration date or reminder to a document. Allow notifications when prompted so LifeNest Docs can notify you about upcoming dates.

Does LifeNest Docs upload my documents?

LifeNest Docs is designed to store documents locally. It does not require a developer-hosted document storage account.

What happens if I delete the app?

Locally stored documents may be permanently lost when you delete the application. Export important files and maintain your own backups.

Face ID isn't working. What should I do?

Confirm that Face ID is configured on your device and that the appropriate permissions are enabled. You may also be able to authenticate using your device passcode.
