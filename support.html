Welcome to LifeNest Docs Support

LifeNest Docs helps you scan, organize, search, and keep track of important personal documents. You'll find answers to common questions below.

How do I add a document?

Open LifeNest Docs and select Add a document. Enter a title and choose the appropriate category.

You can scan a document using the built-in document scanner, import a supported PDF or image, or photograph a document using your device's camera.

Can I scan multi-page documents?

Yes. The built-in document scanner supports multiple pages. The scanned pages are combined into a PDF and saved as a single LifeNest Docs document.

How many documents can I save for free?

The free version of LifeNest Docs allows you to save up to 7 documents.

A multi-page document saved as one LifeNest Docs document counts as one document toward this limit.

What does LifeNest Docs Pro include?

LifeNest Docs Pro removes the document limit and allows you to organize unlimited documents.

The lifetime unlock is a one-time $1.99 purchase in the United States, subject to the actual price displayed by the App Store. There is no recurring subscription.

Can I search inside my documents?

Yes. LifeNest Docs uses on-device text recognition to make supported scanned and imported documents searchable.

You can search using document titles, notes, tags, categories, and keywords recognized within the contents of your documents. This makes it possible to locate a document even when the word you're searching for is contained inside the scanned document.

Why can't LifeNest Docs find a word in my document?

Text recognition is automated and may not recognize every word. Recognition quality can be affected by blurry images, handwriting, unusual fonts, poor lighting, low-resolution scans, or other image-quality issues.

For best results, scan documents in good lighting and keep the document as flat and clear as possible.

How do I restore my Pro purchase?

Open LifeNest Docs, go to Settings, and select Restore Purchases.

Make sure you're using the Apple Account associated with your original purchase.

How do reminders work?

When adding or editing a document, you can enter an expiration date and choose when LifeNest Docs should remind you.

LifeNest Docs can schedule a local notification before the expiration date. Notification permission must be enabled for reminders to appear.

How does App Lock work?

App Lock can be enabled from Settings. When enabled, LifeNest Docs uses your device's authentication system, such as Face ID, Touch ID, or your device passcode, to protect access to the app.

LifeNest Docs does not receive or store your biometric data.

Does LifeNest Docs upload my documents?

LifeNest Docs is designed to store your documents locally on your device. It does not require a LifeNest Docs account or upload your documents to a developer-hosted document-storage server.

Can I back up my LifeNest Docs documents?

Yes. Open Settings and select Create LifeNest Docs Backup.

LifeNest Docs creates a ZIP backup containing your document information and stored PDFs or images. You can then use the iOS share sheet to save the backup to Files, AirDrop it, or send it to another location or service you choose.

Your backup may contain sensitive personal documents, so keep exported backup files in a secure location.

Can I share an individual document?

Yes. Open a document and use the available sharing option to send or save its attachment using the iOS share sheet.

What happens if I delete a document?

Deleting a document from LifeNest Docs removes that document and its locally stored attachment from the application's document storage.

Keep independent copies of important records before deleting them.

What happens if I delete the app?

Locally stored LifeNest Docs information may be permanently lost when you delete the application.

Before deleting LifeNest Docs, create a backup or otherwise export any important documents you need to keep.

Face ID or App Lock isn't working. What should I do?

Confirm that Face ID, Touch ID, or a device passcode is configured on your device.

If authentication continues to fail, check your device settings and restart LifeNest Docs.
