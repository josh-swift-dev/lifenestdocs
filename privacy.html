LifeNest Docs

Privacy Policy

Effective Date: October 5, 2026

LifeNest Docs is designed to help you scan, store, search, organize, and manage important personal documents while keeping you in control of your information. This Privacy Policy explains how LifeNest Docs handles information when you use the application.

1. Information You Add

LifeNest Docs allows you to create, scan, import, and organize documents and related information. This may include document images, PDF files, document titles, categories, tags, notes, issue dates, expiration dates, reminders, and other information you choose to provide.

The contents of documents you choose to store may contain personal or sensitive information. You control which documents are added to the application.

2. Local Document Storage

LifeNest Docs is designed to store your documents and related application information locally on your device. The application does not require a LifeNest Docs account and does not use a developer-hosted server to upload or store your documents.

Stored document attachments and application data use available iOS file-protection features. However, no storage system can guarantee absolute security.

Your device's operating system, backup configuration, and services you choose to use may affect whether application information is included in device or system backups.

3. Camera, Document Scanner, Photos, and Files

With your permission or at your direction, LifeNest Docs may access your device camera, document scanner, selected images, or files so that you can scan, photograph, or import documents.

This access is used to provide the document-management functionality you request.

4. Document Text Recognition and Keyword Search

LifeNest Docs may use on-device text recognition, commonly referred to as OCR, to recognize text contained in supported scanned and imported documents.

Recognized text allows LifeNest Docs to make your documents searchable. You can search using information such as document titles, notes, tags, categories, and keywords recognized within document contents.

Document text recognition is performed using functionality available on your device. Recognized document text and search information are stored locally as part of the application's document index. LifeNest Docs does not send your document contents or recognized text to a developer-hosted server for OCR processing.

Text recognition is automated and may not recognize every word accurately.

5. Face ID and Device Authentication

LifeNest Docs offers an optional App Lock feature. If enabled, the application uses Apple's device-owner authentication functionality, which may include Face ID, Touch ID, or your device passcode depending on your device and settings.

LifeNest Docs does not receive or store your Face ID or Touch ID biometric data.

6. Notifications and Reminders

With your permission, LifeNest Docs may schedule local notifications for document expiration dates and reminders.

Notification permissions can be changed through your device's iOS Settings.

7. In-App Purchases

LifeNest Docs offers an optional LifeNest Docs Pro lifetime unlock that removes the free document limit.

Purchases are processed through Apple's App Store using Apple's StoreKit services. The developer does not receive your full payment card information.

8. Backup and Export

LifeNest Docs allows you to create a backup containing your locally stored document information and attachments.

Backups are created only when you request them. A LifeNest Docs backup may contain your document index as well as stored PDFs, images, recognized document text, and related document information.

You can choose to save or share a backup using the iOS share sheet. Once you export a backup from LifeNest Docs, the storage, security, privacy, and subsequent handling of that backup depend on the application, service, device, or location you choose.

Because backups may contain sensitive documents, you should store exported backups in a location you trust.

9. Sharing Individual Documents

LifeNest Docs allows you to share or export document attachments using the iOS share sheet.

LifeNest Docs does not control how another application or service handles information after you choose to share it.

10. Data Retention and Deletion

Documents remain stored by the application until you delete them, remove the application, or otherwise remove application data.

You can delete individual documents within LifeNest Docs. Deleting a document also removes its associated locally stored attachment from the application's document storage.

Deleting LifeNest Docs generally removes its locally stored application data from the device, subject to iOS backup, restoration, and system behavior.

We strongly recommend maintaining independent backups of important documents.

11. Security

LifeNest Docs uses available iOS security functionality, including iOS file protection for stored application data and optional device authentication.

LifeNest Docs is not an end-to-end encrypted cloud vault, and no application or storage method can guarantee absolute security.

We recommend protecting your device with a strong passcode, enabling appropriate device security features, keeping iOS updated, and maintaining secure backups of important records.

12. Third-Party Services

LifeNest Docs relies on Apple-provided platform functionality for features such as in-app purchases, device authentication, document scanning, notifications, file selection, and sharing.

When you intentionally share, export, or save information to another application or service, that service's privacy practices may apply.

13. Children's Privacy

LifeNest Docs is not specifically designed for children under 13 and does not knowingly solicit personal information from children.

14. Changes to This Privacy Policy

This Privacy Policy may be updated when LifeNest Docs functionality or applicable requirements change. Updates will be published on this page with an updated effective date when appropriate.
